# Lumie 
**Lumie** – это Android-приложение для поддержки ментального здоровья, мотивации и тренировки позитивного мышления. 

Приложение генерирует персональные аффирмации с красивыми динамическими фонами, поддерживает работу в фоне, оповещает о новых аффирмациях в уведомлениях и позволяет сохранять любимые карточки.

## Основные возможности приложения
* **Умная генерация контента:** загрузка аффирмаций через ИИ и подбор тематических фонов через Unsplash API с надежным фолбэком на локальные данные (JSON + drawable).
* **Интерактивная лента:** на главном экране лента аффирмаций с использованием VerticalPager – одна аффирмация на экран. Повторный клик на кнопку 🏠 в BottomBar автоматически отскролливает сетку к началу.
* **Избранное:** добавление в «Избранное» доступно как по клику на иконку ❤️, так и через Double Tap по экрану, который триггерит всплывающую анимацию сердца. Есть возможность фильтрации по категориям. Повторный клик на кнопку ⭐ в BottomBar автоматически отскролливает ленту к началу.
* **Кастомизация фона:** возможность заменить фон конкретной аффирмации или установить постоянный статический/динамический фон в настройках.
* **Экспорт и шеринг:** сохранение аффирмации (текст + фон) как единой картинки в галерею или отправка в другие приложения.
* **Фоновая работа:** автоматическое обновление аффирмаций в фоне с настраиваемой периодичностью (6/12/24 часа) и умной загрузкой только по Wi-Fi (через WorkManager).
* **Уведомления:** локальные уведомления при автоматической загрузке новой аффирмации.
* **Гибкие настройки:** выбор категории, темы (Светлая/Темная/Системная), частоты обновлений, Wi-Fi-only режима и т.д.
* **Анимации:** Lottie-анимации для error и empty states.
* **Первый запуск:** чтобы экран не был пустым при первом входе, приложение автоматически загружает одну стартовую аффирмацию.

## Логика загрузки данных
Приложение спроектировано так, чтобы пользователь никогда не оставался без контента. Процесс сборки сущности Affirmation выглядит следующим образом:
                  
                        Запрос текста аффирмации (ИИ API) 
                                        │
               ┌────────────────────────┴────────────────────────┐
            Успешно                                            Ошибка
               │                                                 │ 
               ▼                                                 ▼
           Текст ИИ и                            Рандомный текст из JSON (Assets) и 
         теги для фона                                дефолтные теги категории 
               │                                                 │
               └────────────────────────┬────────────────────────┘
                                        ▼
                           Запрос фона (Unsplash API) 
                                        │
               ┌────────────────────────┴────────────────────────┐
            Успешно                                            Ошибка
               │                                                 │ 
               ▼                                                 ▼
     Ссылка на изображение                           Рандомный фон из Drawable 
               │                                                 │
               └────────────────────────┬────────────────────────┘
                                        ▼
                     Сборка сущности -> Сохранение в Room DB 

## Стек технологий
| Категория | Библиотека / Инструмент |
|:----------|:-----------|
| UI | Jetpack Compose (Material 3), Lottie |
| Архитектурный паттерн | Clean Architecture, MVVM |
| Навигация | Navigation Compose | 
| DI | Hilt | 
| Асинхронность | Kotlin Coroutines, Flow | 
| Сеть | Retrofit, OkHttp, Logging Interceptor | 
| Сериализация | Kotlinx Serialization | 
| Локальная БД | Room | 
| Хранение настроек | DataStore Preferences | 
| Фоновые задачи | WorkManager | 
| Загрузка изображений | Coil 3 | 
| Splash Screen | Core SplashScreen |

* [ ] **Управление данными:** добавить возможность удаления выбранных аффирмаций из локальной базы данных.
* [ ] **Room DB:** реализовать миграцию базы данных.
* [ ] **UX/UI:** добавить онбординг для ознакомления пользователя с фичами при первом запуске приложения.
* [ ] **Интеграция с системой:** разработать виджет.
* [ ] **Новый функционал:** добавить музыку для медитаций и дыхательные практики с пошаговой сменой фаз (вдох / задержка / выдох).
